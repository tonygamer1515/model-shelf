TRELLIS.2 inference cost

Single asset, one NVIDIA H100, as published on the TRELLIS.2-4B card.

Voxel resolutionWall-clockNotes
512³~3 sfastest tier
1024³~17 s~9.6K latent tokens

The sparse 3D VAE downsamples 16× spatially, so a 1024³ asset compresses to roughly 9,600 latent tokens. Needs Linux and a 24 GB+ NVIDIA GPU (verified on A100 / H100), CUDA 12.4 recommended.

Rebuilding this page

One script refetches everything. No token, no account, nothing gated.

scripts/fetch_models.py 
python3 scripts/fetch_models.py --out data/models.json

# GET https://huggingface.co/api/models/<owner>/<name>
# GET https://huggingface.co/<owner>/<name>/raw/main/README.md
#
# Both endpoints are public. The fetcher needs no HF_TOKEN and writes
# data/models.json, which index.html embeds at build time.

The GitHub Action in .github/workflows/pages.yml runs that same script on every push, so the numbers on this page stay current without anyone touching it.
