Generate a 3D asset

Calls microsoft-trellis-2.hf.space directly from your browser. Microsoft's GPU does the work, this page is only a client — so nothing here has to be hosted or paid for.

It is not unlimited, and no client can make it unlimited. The Space runs on Hugging Face's ZeroGPU, which reserves 120 s of quota per call and caps each visitor per day: 2 minutes for guests, 5 minutes for a free HF account, 40 minutes for PRO. That is roughly one asset per day as a guest. The quota is charged to you, not to this site — which is exactly why it works here at all. The Space returns a stack of rendered views as inline images, which is what you see above. It does not return a downloadable GLB over the API — the GLB is produced by a follow-up call that reads server-side state the API never sends back. For the file itself, use the Space's own interface.

The API underneath

Seven named Gradio endpoints on microsoft-trellis-2.hf.space, no auth required, and CORS already allows this origin.

EndpointParametersReturns
/start_session——
/preprocess_imageimageimage (background removed)
/get_seedrandomize, seedseed
/image_to_3dimage + 14 sampling paramsHTML preview
/extract_glbdecimation_target, texture_sizeGLB (state-bound)
/end_session——
three requests, no library 
# 1. upload the image
curl -X POST https://microsoft-trellis-2.hf.space/gradio_api/upload \
     -F "files=@photo.png"
#    -> ["https://.../gradio_api/file=/tmp/gradio/abcd.png"]

# 2. start the job, get an event id
curl -X POST https://microsoft-trellis-2.hf.space/gradio_api/call/image_to_3d \
     -H 'Content-Type: application/json' \
     -d '{"data":[{"path":"<uploaded>","meta":{path:"/tmp/gradio/abcd.png"}},0,"512",
                  7.5,0.7,12,5.0, 7.5,0.5,12,3.0, 1.0,0.0,12,3.0]}'
#    -> {"event_id":"0c96fa360af84a11921eef7fae81c6b2"}

# 3. stream the result
curl -N https://microsoft-trellis-2.hf.space/gradio_api/call/image_to_3d/<event_id>

# Quota errors come back like this, and they are the real ceiling:
#   You have exceeded your ZeroGPU quota (120s requested vs. 176s left).

What an asset costs

Single asset on one NVIDIA H100, as published on the TRELLIS.2-4B card.

Voxel resolutionWall-clockNotes
512³~3 sfastest tier
1024³~17 s~9.6K latent tokens
1536³~60 sfull fidelity

Compute is the cheap part — 3 to 60 seconds. The quota reservation is 120 s flat, so on ZeroGPU the wall-clock barely matters. The sparse 3D VAE downsamples 16× spatially, so a 1024³ asset compresses to roughly 9,600 latent tokens. Self-hosting needs Linux and a 24 GB+ NVIDIA GPU (verified on A100 / H100), CUDA 12.4 recommended.
